# -Data-Preparation-
Скрипт на Python для быстрой генерации синтетической базы пользователей (ФИО и Email) и экспортом в формат CSV.

# 👥 Fake User Data Generator

[![Python Version](https://shields.io)](https://python.org)

Лёгкий и быстрый Python-скрипт для генерации реалистичных тестовых данных. Идеально подходит, когда нужно быстро забить базу данных, протестировать фронтенд или проверить работу сортировки, не разворачивая тяжелые библиотеки вроде Faker.

---

## ⚡ Главные фишки

* **Gender Sync:** Имена и фамилии согласованы по полу. Больше никаких *«Анна Иванов»* в ваших тестах.
* **Excel-Ready:** Файл сохраняется в кодировке `utf-8-sig`. Никаких «кракозябр» и сломанной кириллицы при открытии в Microsoft Excel.
* **Zero Dependencies:** Используются только стандартные библиотеки Python (`csv`, `random`, `string`). Не нужно ничего устанавливать через `pip`.

## 🚀 Быстрый старт

### 1. Запуск «из коробки»
Просто скачайте скрипт и запустите его в терминале. Он автоматически создаст файл на 50 пользователей:
```bash
python main.py
```

### 2. Кастомизация (для продвинутых)
Вы можете импортировать функцию в любой другой свой скрипт и гибко настраивать количество строк и имя итогового файла:

```python
from main import generate_users_data

# Генерируем 500 пользователей в отдельный файл
generate_users_data(filename="production_test_users.csv", count=500)
```
